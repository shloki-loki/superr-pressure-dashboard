# SupeRR Selector pressure review

Serve this directory over HTTP or deploy it to Vercel as a static site. For a local review, run `python3 -m http.server 8000` in this directory and visit `http://localhost:8000`.

The dashboard automatically loads the published retrospective analysis from `data.json`. Rankings use the supplied 60/40, 70/30 and 80/20 results. Player profiles show fixed-model match-removal sensitivity for the default 70/30 blend. The Ball lab uses the published branch calculations. The dashboard is a provisional review.
